Connectors link your Airv agent to external platforms — email, calendar, ad networks, social media, and more — through Composio's OAuth toolkit. You use this API to see which connections are active, generate OAuth redirect links so users can authorise new integrations, and force-sync status changes from Composio. The first time a sync detects an active connection, Airv automatically installs the corresponding MCP server so your agent can start using the integration immediately.

<Note>
  Connection state is managed by Composio. Airv reflects that state in real time after each sync. If a connection appears stale, call `PUT /api/connectors` to pull the latest status.
</Note>

## List connections

### `GET /api/connectors`

Returns two arrays: the full catalogue of available toolkits and every connection currently associated with your account along with its status.

<CodeGroup>
```bash cURL
curl -s https://air.wzrd.tech/api/connectors \
  --cookie "session=<your-session-cookie>"
```

```typescript TypeScript
const res = await fetch('https://air.wzrd.tech/api/connectors', {
  credentials: 'include',
});
const { toolkits, connections } = await res.json();
```
</CodeGroup>

**Response** — `200 OK`

<ResponseField name="toolkits" type="array">
  Catalogue of available Composio toolkits.
</ResponseField>

<ResponseField name="toolkits[].slug" type="string">
  The toolkit slug used when creating a connection, e.g. `"gmail"`, `"google_calendar"`.
</ResponseField>

<ResponseField name="toolkits[].name" type="string">
  Human-readable display name of the toolkit.
</ResponseField>

<ResponseField name="toolkits[].logo" type="string | null">
  URL to the toolkit's logo image, or `null` if unavailable.
</ResponseField>

<ResponseField name="connections" type="array">
  All connections associated with your account.
</ResponseField>

<ResponseField name="connections[].toolkit" type="string">
  The Composio toolkit slug for this connection, e.g. `"gmail"`, `"twitter"`.
</ResponseField>

<ResponseField name="connections[].status" type="string">
  Current connection status. One of `"active"`, `"pending"`, or `"expired"`.
</ResponseField>

<ResponseField name="connections[].connected_at" type="string | null">
  ISO 8601 timestamp of when the connection became active, or `null` if it hasn't activated yet.
</ResponseField>

```json
{
  "toolkits": [
    {
      "slug": "gmail",
      "name": "Gmail",
      "logo": "https://cdn.composio.dev/logos/gmail.png"
    },
    {
      "slug": "google_calendar",
      "name": "Google Calendar",
      "logo": "https://cdn.composio.dev/logos/google_calendar.png"
    }
  ],
  "connections": [
    {
      "toolkit": "gmail",
      "status": "active",
      "connected_at": "2024-05-01T12:00:00Z"
    },
    {
      "toolkit": "twitter",
      "status": "pending",
      "connected_at": null
    }
  ]
}
```

## Create an OAuth link session

### `POST /api/connectors`

Generates a Composio OAuth redirect URL for a specific toolkit. Redirect the user to this URL to complete authorisation. After the user grants access, Composio calls back and the connection status updates to `"active"` on the next sync.

<ParamField body="toolkit" type="string" required>
  The Composio toolkit slug to connect, e.g. `"gmail"`, `"google_calendar"`, `"twitter"`, `"linkedin"`. Must be lowercase alphanumeric with hyphens or underscores, up to 64 characters.
</ParamField>

<CodeGroup>
```bash cURL
curl -s -X POST https://air.wzrd.tech/api/connectors \
  -H "Content-Type: application/json" \
  --cookie "session=<your-session-cookie>" \
  -d '{ "toolkit": "gmail" }'
```

```typescript TypeScript
const res = await fetch('https://air.wzrd.tech/api/connectors', {
  method: 'POST',
  credentials: 'include',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ toolkit: 'gmail' }),
});
const { redirect_url } = await res.json();
// Redirect the user:
window.location.href = redirect_url;
```
</CodeGroup>

**Response** — `200 OK`

<ResponseField name="redirect_url" type="string">
  The Composio OAuth URL to which you should redirect the user. The URL is short-lived; use it promptly.
</ResponseField>

```json
{
  "redirect_url": "https://backend.composio.dev/api/v1/auth/link/eyJhb..."
}
```

<Tip>
  After the OAuth flow completes, call `PUT /api/connectors` to sync the new connection into Airv and trigger MCP installation.
</Tip>

## Sync connection statuses

### `PUT /api/connectors`

Pulls the latest connection statuses from Composio and updates Airv's local records. If this sync detects at least one newly active connection and no MCP server is yet installed, Airv installs MCP automatically in the background.

<CodeGroup>
```bash cURL
curl -s -X PUT https://air.wzrd.tech/api/connectors \
  --cookie "session=<your-session-cookie>"
```

```typescript TypeScript
const res = await fetch('https://air.wzrd.tech/api/connectors', {
  method: 'PUT',
  credentials: 'include',
});
const { connections } = await res.json();
```
</CodeGroup>

**Response** — `200 OK`

<ResponseField name="connections" type="array">
  Full updated list of your connection objects, in the same shape as the `GET` response `connections` array.
</ResponseField>

```json
{
  "connections": [
    {
      "toolkit": "gmail",
      "status": "active",
      "connected_at": "2024-05-01T12:00:00Z"
    }
  ]
}
```

## Error cases

| Status | Meaning |
|--------|---------|
| `400` | Missing or unrecognised `toolkit` slug in a `POST` request. |
| `401` | Session cookie is missing or expired. |
| `502` | Composio is unreachable. The sync or OAuth session could not be completed. Retry shortly. |
| `500` | Internal error. |

<Warning>
  OAuth redirect URLs expire quickly. If the user does not complete authorisation within a few minutes, generate a new link by calling `POST /api/connectors` again.
</Warning>
