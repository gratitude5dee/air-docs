The Assets API gives you full control over the creative files your Airv agent generates and stores. You can list everything in your library, pull in assets from Box to make them available to the agent, fetch a single asset along with its delivery records, or revoke all deliveries for an asset when you want to retire it. Delivery URLs are short-lived by design; request a fresh one any time you need to share or embed an asset.

<Note>
  Your library holds up to **200 assets**. The `GET /api/assets` list endpoint caps its response at 200 items. If you need finer-grained access, fetch individual assets by ID.
</Note>

---

## List assets

### `GET /api/assets`

Returns up to 200 creative assets in your library, ordered by creation date descending. Each object includes the asset's internal identifiers and storage metadata. Use `GET /api/assets/[id]` to retrieve delivery records for a specific asset.

<CodeGroup>
```bash cURL
curl -s https://air.wzrd.tech/api/assets \
  --cookie "session=<your-session-cookie>"
```

```typescript TypeScript
const res = await fetch('https://air.wzrd.tech/api/assets', {
  credentials: 'include',
});
const { assets } = await res.json();
```
</CodeGroup>

**Response** — `200 OK`

<ResponseField name="assets" type="array">
  Array of asset objects (up to 200).
</ResponseField>

<ResponseField name="assets[].id" type="string">
  Unique asset identifier.
</ResponseField>

<ResponseField name="assets[].box_asset_id" type="string">
  The Box file ID this asset was ingested from.
</ResponseField>

<ResponseField name="assets[].sha256" type="string">
  SHA-256 content hash of the asset file.
</ResponseField>

<ResponseField name="assets[].ext" type="string">
  File extension, e.g. `"png"`, `"mp4"`, `"svg"`.
</ResponseField>

<ResponseField name="assets[].kind" type="string">
  Asset kind as classified by the pipeline, e.g. `"image"`, `"video"`.
</ResponseField>

<ResponseField name="assets[].bytes" type="number">
  File size in bytes.
</ResponseField>

<ResponseField name="assets[].created_at" type="string">
  ISO 8601 timestamp of when the asset was added to your library.
</ResponseField>

```json
{
  "assets": [
    {
      "id": "ast_001",
      "box_asset_id": "1234567890",
      "sha256": "e3b0c44298fc1c149afb…",
      "ext": "png",
      "kind": "image",
      "bytes": 204800,
      "created_at": "2024-06-10T10:00:00Z"
    },
    {
      "id": "ast_002",
      "box_asset_id": "0987654321",
      "sha256": "a665a45920422f9d417e…",
      "ext": "mp4",
      "kind": "video",
      "bytes": 10485760,
      "created_at": "2024-06-09T14:30:00Z"
    }
  ]
}
```

## Ingest a Box asset

### `POST /api/assets`

Pulls an asset from Box into your Airv library and returns the new asset record along with a short-TTL delivery URL you can use immediately. This operation can take up to 300 seconds for large files.

<ParamField body="box_asset_id" type="string" required>
  The Box file ID to ingest. Must be alphanumeric with hyphens or underscores, up to 64 characters.
</ParamField>

<ParamField body="purpose" type="string">
  An optional tag describing how the asset will be used, e.g. `"social_post"`, `"ad"`, `"thumbnail"`. Stored on the delivery record and helps the agent contextualise the file.
</ParamField>

<CodeGroup>
```bash cURL
curl -s -X POST https://air.wzrd.tech/api/assets \
  -H "Content-Type: application/json" \
  --cookie "session=<your-session-cookie>" \
  -d '{ "box_asset_id": "1234567890", "purpose": "social_post" }'
```

```typescript TypeScript
const res = await fetch('https://air.wzrd.tech/api/assets', {
  method: 'POST',
  credentials: 'include',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ box_asset_id: '1234567890', purpose: 'social_post' }),
});
const data = await res.json();
```
</CodeGroup>

**Response** — `200 OK`

<ResponseField name="asset_id" type="string">
  Unique identifier for the newly ingested asset.
</ResponseField>

<ResponseField name="sha256" type="string">
  SHA-256 content hash of the ingested file.
</ResponseField>

<ResponseField name="delivery_id" type="string">
  Identifier for the delivery record associated with this ingest.
</ResponseField>

<ResponseField name="url" type="string">
  A short-lived URL you can use to download or embed the asset right now. Do not persist this value — request a fresh delivery URL via `GET /api/assets/[id]` when you need it again.
</ResponseField>

<ResponseField name="expires_at" type="string">
  ISO 8601 timestamp when the `url` expires.
</ResponseField>

```json
{
  "asset_id": "ast_003",
  "sha256": "b94f6f125c79e3a5ffaa…",
  "delivery_id": "del_007",
  "url": "https://cdn.air.wzrd.tech/deliver/ast_003?token=eyJhb...&exp=1718012800",
  "expires_at": "2024-06-10T12:00:00Z"
}
```

<Warning>
  The `url` is short-lived. If you need a fresh URL later, call `GET /api/assets/[id]` to retrieve current delivery records.
</Warning>

## Get asset detail

### `GET /api/assets/[id]`

Returns full metadata for a single asset, including all delivery records. Delivery records show their expiry and revocation status; use the `url` from a non-expired, non-revoked delivery to access the file.

<ParamField path="id" type="string" required>
  The asset ID, as returned by `GET /api/assets` or `POST /api/assets`.
</ParamField>

<CodeGroup>
```bash cURL
curl -s https://air.wzrd.tech/api/assets/ast_001 \
  --cookie "session=<your-session-cookie>"
```

```typescript TypeScript
const res = await fetch('https://air.wzrd.tech/api/assets/ast_001', {
  credentials: 'include',
});
const { asset, deliveries } = await res.json();
```
</CodeGroup>

**Response** — `200 OK`

<ResponseField name="asset" type="object">
  Full asset metadata in the same shape as entries in the `GET /api/assets` list.
</ResponseField>

<ResponseField name="deliveries" type="array">
  Up to 50 delivery records for this asset, most recent first.
</ResponseField>

<ResponseField name="deliveries[].id" type="string">
  Unique delivery record identifier.
</ResponseField>

<ResponseField name="deliveries[].purpose" type="string | null">
  The purpose tag supplied when this delivery was created, if any.
</ResponseField>

<ResponseField name="deliveries[].expires_at" type="string">
  ISO 8601 timestamp when this delivery URL expires.
</ResponseField>

<ResponseField name="deliveries[].revoked_at" type="string | null">
  ISO 8601 timestamp when this delivery was revoked, or `null` if it is still active.
</ResponseField>

<ResponseField name="deliveries[].created_at" type="string">
  ISO 8601 timestamp when the delivery was created.
</ResponseField>

```json
{
  "asset": {
    "id": "ast_001",
    "box_asset_id": "1234567890",
    "sha256": "e3b0c44298fc1c149afb…",
    "ext": "png",
    "kind": "image",
    "bytes": 204800,
    "created_at": "2024-06-10T10:00:00Z"
  },
  "deliveries": [
    {
      "id": "del_007",
      "purpose": "social_post",
      "expires_at": "2024-06-10T12:00:00Z",
      "revoked_at": null,
      "created_at": "2024-06-10T10:00:00Z"
    }
  ]
}
```

## Revoke all deliveries

### `DELETE /api/assets/[id]`

Revokes every active delivery for the specified asset. The asset record itself is not deleted — only its delivery records are revoked. After revocation the asset remains in your library but its download URLs stop working.

<ParamField path="id" type="string" required>
  The asset ID whose deliveries you want to revoke.
</ParamField>

<CodeGroup>
```bash cURL
curl -s -X DELETE https://air.wzrd.tech/api/assets/ast_001 \
  --cookie "session=<your-session-cookie>"
```

```typescript TypeScript
const res = await fetch('https://air.wzrd.tech/api/assets/ast_001', {
  method: 'DELETE',
  credentials: 'include',
});
const { revoked } = await res.json();
```
</CodeGroup>

**Response** — `200 OK`

<ResponseField name="revoked" type="number">
  Number of delivery records that were revoked.
</ResponseField>

```json
{
  "revoked": 1
}
```

## Error cases

| Status | Meaning |
|--------|---------|
| `400` | `box_asset_id` is missing or malformed in a `POST` request. |
| `401` | Session cookie is missing or expired. |
| `404` | No asset with the given ID exists in your library. |
| `429` | Your agent is currently busy and cannot process an ingest right now. Retry shortly. |
| `502` | Ingest failed — the file could not be retrieved or processed. Check the `box_asset_id` and retry. |
| `504` | Ingest timed out after 300 seconds. The file may be too large or Box is slow to respond. |
| `500` | Internal error. |
