The Airv web app at [air.wzrd.tech](https://air.wzrd.tech) is your agent's full control center. Beyond chatting, it's where you manage approvals, install skills, connect integrations, and access your agent's cloud desktop — all from a browser, with no installation required.

## Logging In

Sign in at [air.wzrd.tech](https://air.wzrd.tech) with your phone number. You'll receive a one-time passcode (OTP) via SMS. Enter it and you're in — there's no password to set or reset.

<Note>
  Use the same phone number associated with your Airv account. If you signed up with a different number than your iMessage number, use the one you registered with.
</Note>

### Creative Slash Commands

| Command | What it does |
|---|---|
| `/imagine <description>` | Generates a static image from your description |
| `/animate <description>` | Generates a short video from your description |
| `/zap <description>` | Quick-generation shortcut for fast creative output |

<Tip>
  Be specific in your descriptions. Instead of `/imagine a landscape`, try `/imagine a misty mountain valley at dawn, soft golden light, photorealistic` for much better results.
</Tip>

## Desktop Pairing

Pair the Airv web app with your local machine for a desktop-native chat experience. Once paired, you can interact with your agent through a native window without keeping a browser tab open.

<Info>
  Desktop pairing is available for macOS and Windows. Find the pairing option under **Settings → Desktop App** in the web app.
</Info>

## Session Security

Your session is protected by design, not just by configuration.

- Your session cookie is `httpOnly` — browser JavaScript cannot read or leak it.
- Box tokens and API keys your agent uses for integrations never appear in the browser. They live server-side inside your agent's secure enclave.
- OAuth flows redirect through Airv's backend so your raw access tokens are never stored in local storage or visible in network requests from the browser.

<Warning>
  Never share your session or let someone else use your logged-in browser window. All actions taken in the web app are attributed to you as the account owner.
</Warning>
